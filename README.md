# Anita Party

Boîte à jeux sur tablette pour l'anniversaire d'Anita : 4 équipes, buzzers, scores en fil rouge et grande finale.

Jeux : Qui est le plus…, Le Duel, Blind test, Anita ou pas Anita ?, La Taupe, Kahoot (report des points).

Tout tient dans `index.html` (aucune installation). Les scores et le contenu préparé sont enregistrés sur l'appareil.

Pour l'installer sur la tablette : ouvrir la page dans Chrome, menu ⋮ → « Ajouter à l'écran d'accueil ».
